# Portainer

## What it is

A web UI for managing Docker containers, images, volumes, networks without typing every command by hand.

## Why I set it up

Mostly convenience. I still use the CLI for anything that actually matters (especially after the disk-exhaustion incident, where digging through `docker system df -v` and volume inspection by hand was the only way to actually find the problem), but Portainer is useful for a quick look at what's running or restarting something without hunting for the exact container name.
